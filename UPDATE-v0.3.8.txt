Budget Local v0.3.8 — Qwen3 Local AI

WHAT IS NEW
- Smart Add now has optional Local AI.
- Model: onnx-community/Qwen3-0.6B-ONNX.
- Runtime: Transformers.js 4.2.0 vendored into /ai during the Cloudflare build.
- Inference: WebGPU on the device.
- Quantization: q4f16.
- The supported Transformers.js q4f16 model file is about 570 MB, plus tokenizer/runtime.
  (The separate 543 MB ORT-GenAI optimized artifact is not the normal Transformers.js
  browser pipeline path, so this build uses the officially documented q4f16 path.)
- Model is NOT stored in the Cloudflare deployment. It downloads only when the user
  enables Local AI and is then cached by the browser.

SMART ADD AI
- New "Enable Local AI" model manager.
- Visible download/progress state.
- New "Interpretar con AI" button.
- Existing deterministic parser remains as "Interpretar sin AI" fallback.
- AI extracts:
    expense/income
    amount
    merchant/payee
    real Actual category
    subcategory
    account only when explicitly mentioned
    date
    confidence
- AI is given the current real category names from Actual Budget.
- AI is given the user's locally stored subcategories.
- If a subcategory name also exists as a real main category, it is not offered as
  a subcategory. Example: Mortgage can remain its own real category/card.

RECEIPTS
- Tesseract OCR remains local.
- When Qwen is already ready, receipt OCR is automatically organized/classified
  by Qwen after OCR.
- If AI fails, the existing deterministic receipt parser is used automatically.

LOCAL LEARNING
- Review card includes "Remember merchant".
- When the user explicitly taps it, merchant -> category/subcategory is stored only
  in localStorage and supplied to Qwen on future Smart Add requests.
- The app does not silently learn an unconfirmed category.

SAFETY / FINANCIAL DATA
- AI never writes a transaction directly.
- Output still goes through Actual Budget's normal Review & Save screen.
- Subcategory is stored as a note tag, while the transaction remains in the main
  Actual category so it subtracts from the correct category budget.
- "Quitar modelo local" deletes only Transformers model cache/marker; it does not
  clear Actual Budget data, Safari site data, transactions, or budgets.

FALLBACK
- If WebGPU is unavailable, normal Smart Add + OCR continue to work.
- No OpenAI API, Firebase or Supabase is needed for Local AI inference.
